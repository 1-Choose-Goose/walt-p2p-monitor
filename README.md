# Walt P2P Monitor 1.5

Многопользовательский Telegram-бот для мониторинга P2P-цен Walt в рублях. Поддерживаются все актуальные монеты P2P Walt: `GRAM`, `USDT`, `BTC`, `NOT` и `ETH`. Бот показывает цены покупки и продажи, биржевой курс в рублях, отслеживает пороги и процентные изменения и отправляет сводки.

Функция «Выгодные лоты» сравнивает P2P-предложения с биржевым курсом. Каждый пользователь выбирает покупку, продажу или оба направления и собственную минимальную наценку. История отправленных ID сохраняется после перезапуска, поэтому одно объявление не дублируется.

За один опрос бот безопасно просматривает не более трёх страниц Walt (до 150 объявлений на направление) и выбирает минимальную цену покупки либо максимальную цену продажи из этой выборки. Это ограничивает нагрузку на API; результат не заявляется как абсолютный лучший лот всего рынка. Ошибка одной валюты или направления не скрывает доступные сведения по остальным, а без свежего курса Coinbase сравнительный сигнал не формируется.

Монеты, сумма сделки, допустимый минимальный лимит объявления, направления и способы оплаты настраиваются индивидуально. Доступны СБП, Сбербанк, другие российские банки или любой способ оплаты. В сводке отображаются продавец, лимиты, способы оплаты и ссылка на выбранное объявление Walt.

Новый пользователь отправляет боту свой системный контакт Telegram. Номер принимается только из собственного контакта и привязывается к Telegram ID. Администратор `768929900` получает заявку, назначает доступ и роль, после чего пользователь добавляет личный токен Walt. Токены шифруются перед сохранением и не выводятся в журналах.

Основные действия доступны через компактное русское кнопочное меню. Бот запоминает настройки, удаляет обработанные сообщения пользователя и заменяет своё предыдущее сообщение, чтобы не засорять чат.

## Команды

- `/price` — текущие отобранные цены;
- `/deals` — автоуведомления о расчётно выгодных лотах;
- `/alert` — ценовой порог;
- `/change` — уведомление по процентному изменению;
- `/schedule` — периодическая или ежедневная сводка;
- `/alerts` и `/delete` — просмотр и удаление правил;
- `/pause` и `/resume` — пауза и возобновление уведомлений.

Администратор фиксирован в коде и не может быть удалён, понижен или заменён переменной окружения. Для остальных аккаунтов доступны роли USER и PREMIUM, отзыв, восстановление и полное удаление доступа.

## Локальная разработка

```powershell
uv sync --all-extras --frozen
Copy-Item .env.example .env
# Для локального Windows-запуска замените DATABASE_PATH на ./data/walt-price-bot.db
# Заполните .env, затем:
uv run pytest
uv run ruff check src tests
uv run python -m walt_price_bot.main
```

## Сервер

Переменные хранятся в `/etc/walt-price-bot.env`, а SQLite — в `/var/lib/walt-price-bot/walt-price-bot.db`. Код устанавливается в `/opt/walt-price-bot` и запускается службой `walt-price-bot.service`. Перед повторной установкой существующая база копируется рядом с суффиксом `.pre-upgrade.<UTC-время>`. Ключ шифрования создаётся установщиком один раз и хранится с правами `0600`.

Проверка:

```bash
systemctl status walt-price-bot --no-pager
journalctl -u walt-price-bot -n 100 --no-pager
```
