# Walt P2P Monitor 1.7

Многопользовательский Telegram-бот для мониторинга P2P-цен Walt в рублях. Поддерживаются все актуальные монеты P2P Walt: `GRAM`, `USDT`, `BTC`, `NOT` и `ETH`. Бот показывает цены покупки и продажи, биржевой курс в рублях, отслеживает пороги и процентные изменения и отправляет сводки.

Функция «Выгодные лоты» сравнивает с биржевым курсом все подходящие объявления в полученной выборке Walt. Каждый пользователь выбирает покупку, продажу или оба направления и собственную минимальную наценку. В сообщении показывается до пяти лучших предложений на валюту и направление, а остальные доступны в постраничной истории в течение 10 минут. Новые объявления отправляются сразу; то же объявление может повториться через 10 минут, если всё ещё подходит.

За один опрос бот безопасно просматривает не более трёх страниц Walt (до 150 объявлений на направление). Для «Текущих цен» он по-прежнему выбирает одну минимальную цену покупки и одну максимальную цену продажи, а для выгодных лотов анализирует весь отфильтрованный список без дополнительных запросов. Результат не заявляется как абсолютный лучший лот всего рынка. Повреждённое отдельное объявление пропускается, но некорректная структура всего ответа считается ошибкой источника. Ошибка одной валюты или направления не скрывает доступные сведения по остальным, а без свежего курса Coinbase сравнительный сигнал не формируется.

Справочный курс Coinbase можно скрыть в обычных сводках. Эта настройка не отключает внутреннее сравнение для «Выгодных лотов». Один краткосрочно кэшированный публичный курс может использоваться несколькими пользователями; данные Walt всегда запрашиваются с личным токеном и не переиспользуются между аккаунтами.

Монеты, сумма сделки, допустимый минимальный лимит объявления, направления и способы оплаты настраиваются индивидуально. Доступны СБП, Сбербанк, другие российские банки или любой способ оплаты. В сводке отображаются продавец, лимиты, способы оплаты и ссылка на выбранное объявление Walt.

Новый пользователь отправляет боту свой системный контакт Telegram. Номер принимается только из собственного контакта и привязывается к Telegram ID. Администратор `768929900` получает заявку, назначает доступ и роль, после чего пользователь добавляет личный токен Walt. Токены шифруются перед сохранением и не выводятся в журналах.

Основные действия доступны через компактное русское кнопочное меню. Бот запоминает настройки, удаляет обработанные сообщения пользователя и заменяет своё предыдущее сообщение, чтобы не засорять чат. События одного мониторингового цикла объединяются, поэтому одновременно сработавшие уведомления не удаляют друг друга.

Общий планировщик проверяет, не пора ли обслужить аккаунт, не реже чем раз в 15 секунд. Реальные HTTP-запросы для каждого пользователя выполняются только после его индивидуального интервала; выполнение ограничено пятью одновременными аккаунтами. Во время тихих часов рынок для аккаунта не опрашивается и события не отмечаются доставленными. После их окончания бот оценивает только текущее состояние рынка и не рассылает пакет устаревших сигналов. Общая очистка просроченной истории выполняется раз в минуту независимо от тихих часов.

## Команды

- `/price` — текущие отобранные цены;
- `/deals` — автоуведомления о расчётно выгодных лотах;
- `/alert` — ценовой порог;
- `/change` — уведомление по процентному изменению;
- `/schedule` — периодическая или ежедневная сводка;
- `/alerts` и `/delete` — просмотр и удаление правил;
- `/pause` и `/resume` — пауза и возобновление уведомлений.

Администратор фиксирован в коде и не может быть удалён, понижен или заменён переменной окружения. Для остальных аккаунтов доступны роли USER и PREMIUM, отзыв, восстановление и полное удаление доступа.

## Локальная разработка

```powershell
uv sync --all-extras --frozen
Copy-Item .env.example .env
# Для локального Windows-запуска замените DATABASE_PATH на ./data/walt-price-bot.db
# Заполните .env, затем:
uv run pytest
uv run ruff check src tests
uv run python -m walt_price_bot.main
```

## Сервер

Переменные хранятся в `/etc/walt-price-bot.env`, а SQLite — в `/var/lib/walt-price-bot/walt-price-bot.db`. Код устанавливается в `/opt/walt-price-bot` и запускается службой `walt-price-bot.service`. Установщик до остановки службы проверяет файлы, зависимости и конфигурацию, затем останавливает службу и сохраняет окончательное состояние базы через SQLite Backup API в файл `.pre-upgrade.<UTC-время>`. До запуска новой версии он применяет миграцию и проверяет целостность SQLite; успешным обновление считается после нескольких последовательных проверок работающей службы. Предыдущий релиз остаётся в `/opt/walt-price-bot.previous.<UTC-время>`; при ошибке код, unit-файл и база восстанавливаются автоматически. Ключ шифрования создаётся только при его отсутствии и хранится с правами `0600`.

Безопасное обновление из каталога релиза:

```bash
sudo bash deploy/install.sh "$PWD"
systemctl is-active walt-price-bot.service
journalctl -u walt-price-bot -n 100 --no-pager
```

Если после успешного запуска нужен ручной откат, остановите службу, переименуйте текущий `/opt/walt-price-bot`, верните точный каталог `.previous.<UTC-время>` в `/opt/walt-price-bot`, при необходимости восстановите базу из соответствующего `.pre-upgrade.<UTC-время>` через SQLite Backup API и снова запустите службу. Не копируйте работающую WAL-базу обычным `cp`.

Проверка:

```bash
systemctl status walt-price-bot --no-pager
journalctl -u walt-price-bot -n 100 --no-pager
```
