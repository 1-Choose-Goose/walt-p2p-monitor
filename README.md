# Walt P2P Monitor

Telegram-бот для мониторинга P2P-цен `USDT/RUB`, `TON/RUB` и `BTC/RUB` в Walt. Бот показывает цены покупки и продажи, актуальный биржевой курс Coinbase в рублях, отслеживает пороги и процентные изменения, а также отправляет сводки по расписанию. Сделки не совершаются.

Функция «Выгодные лоты» автоматически сравнивает подходящие P2P-предложения с биржевым курсом. Владелец выбирает покупку, продажу или оба направления и минимальную расчётную разницу: 0,5%, 1%, 2% или 3%. История отправленных ID хранится в SQLite до изменения настроек функции, поэтому объявление не повторяется даже после чередования лидеров или перезапуска. Несколько подходящих предложений объединяются в одно уведомление.

За один опрос бот безопасно просматривает не более трёх страниц Walt (до 150 объявлений на направление) и выбирает минимальную цену покупки либо максимальную цену продажи из этой выборки. Это ограничивает нагрузку на API; результат не заявляется как абсолютный лучший лот всего рынка. Ошибка одной валюты или направления не скрывает доступные сведения по остальным, а без свежего курса Coinbase сравнительный сигнал не формируется.

Для покупки и продажи учитываются онлайн-объявления с минимальным лимитом от 500 до 2 000 ₽. Для покупки дополнительно требуется оплата через СБП, Сбербанк или другой поддерживаемый российский банк. Максимальный лимит не ограничивается. В сводке отображаются никнейм и номер объявления, а прямая ссылка открывает выбранное объявление в Walt.

Основные действия доступны через русское кнопочное меню. Команда `/start` и кнопка «Назад в меню» возвращают на главный экран. Сообщения пользователя удаляются после обработки, а предыдущее сообщение бота заменяется актуальным, чтобы чат не засорялся. До первого запуска Telegram показывает русское описание возможностей бота и команду `/start`, по которой можно сразу открыть меню.

## Команды

- `/price` — текущие отобранные цены;
- `/deals` — автоуведомления о расчётно выгодных лотах;
- `/alert` — ценовой порог;
- `/change` — уведомление по процентному изменению;
- `/schedule` — периодическая или ежедневная сводка;
- `/alerts` и `/delete` — просмотр и удаление правил;
- `/pause` и `/resume` — пауза и возобновление уведомлений.

Первый `/start` атомарно закрепляет бота за владельцем, если `OWNER_TELEGRAM_ID` не задан заранее. Если сохранённый владелец отличается от `OWNER_TELEGRAM_ID`, запуск завершается с явной ошибкой и владелец в базе не меняется.

## Локальная разработка

```powershell
uv sync --all-extras --frozen
Copy-Item .env.example .env
# Для локального Windows-запуска замените DATABASE_PATH на ./data/walt-price-bot.db
# Заполните .env, затем:
uv run pytest
uv run ruff check src tests
uv run python -m walt_price_bot.main
```

## Сервер

Переменные хранятся в `/etc/walt-price-bot.env`, а SQLite — в `/var/lib/walt-price-bot/walt-price-bot.db`. Код устанавливается в `/opt/walt-price-bot` и запускается службой `walt-price-bot.service`. Перед повторной установкой существующая база копируется рядом с суффиксом `.pre-upgrade.<UTC-время>`. Расписания рассчитываются в `TIMEZONE` (по умолчанию `Asia/Yekaterinburg`).

Проверка:

```bash
systemctl status walt-price-bot --no-pager
journalctl -u walt-price-bot -n 100 --no-pager
```
